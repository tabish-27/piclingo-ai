# 📸 PicLingo AI — Smart Image Caption & Quote Generator

PicLingo AI is a modern full-stack web application that transforms user-uploaded images into intelligent, context-aware captions and inspirational quotes using advanced Multimodal AI models.

---

## 🚀 Key Features
- 🖼️ **Image Analysis:** Deep contextual understanding of uploaded pictures.
- ✍️ **Intelligent Captions:** Generates relevant, creative, and engaging captions.
- ⚡ **Full-Stack Architecture:** Responsive React frontend paired with an Express.js backend.
- 🔐 **Clean & Secure:** API-driven architecture ready for cloud deployment.

---

## 🛠️ Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS / Modern CSS
- **Backend:** Node.js, Express.js
- **AI Integration:** Multimodal Vision AI API
- **Version Control:** Git & GitHub
